# StackOverflow #79197012: Next.js Parallel Route and Intercepting Route compiled on dev mode, but not working on production build

- **Tags**: next.js, build-error, parallel-route, intercepting-route

## Description & Technical Context

We are working on a Next.js 14 project with the following routes:

Our App router

```
app/[lang]/(frontend)/...
app/[lang]/(admin)/admin/...
app/[lang]/(auth)/auth/...

```


`app/[lang]/layout.tsx` contains:

<html>
    <head />
    {children}
</html>


`app/[lang]/(frontend)/layout.tsx` contains:

<body class="frontend">
    {children}
</body>


`app/[lang]/(frontend)/layout.tsx` contains:

<body class="admin">
    {children}
</body>


Here are the HTML and Body tag mapping according to the routes:


```
app/[lang]/layout.tsx             <--- html, head
app/[lang]/(frontend)/layout.tsx  <--- body.frontend
app/[lang]/(admin)/layout.tsx     <--- body.admin

```


With this base we're trying to implement a modal/drawer feature using the intercepted and parallel routes.


The point where we're exercising is:


```
app/[lang]/(admin)/(admin-pages)/example-intercepted/

```

The Interception

We're trying to implement drawer/modal for `/create` route.


`app/[lang]/(admin)/(admin-pages)/example-intercepted/layout.tsx`:

export interface IProps {
  children: React.ReactNode;
  slot: React.ReactNode;
}

export default function InterceptedLayout({ children, slot }: any) {
  return (
    <>
      {children}
      {slot}
    </>
  );
}


`app/[lang]/(admin)/(admin-pages)/example-intercepted/page.tsx`:

import Link from "next/link";
...
return (
    <>
        List Page
        <Link href="http://localhost:3000/en/admin/example-intercepted/create">
            Add New
        </Link>
    </>
);
...


`app/[lang]/(admin)/(admin-pages)/example-intercepted/create/page.tsx`:

// server-side component
return (
    <ExampleForm /> // <--- client-side component
)


`app/[lang]/(admin)/(admin-pages)/example-intercepted/@slot/(.)create/page.tsx`:

export default function Page() {
  return <>I am not working</>;
}
